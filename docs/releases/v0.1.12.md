# Speech Bubble 4koma Editor v0.1.12

## 日本語

自動復元の安全性を強化したWindowsスタンドアロン版のメンテナンスリリースです。

- レイアウトが参照する画像IDがautosaveの画像一覧に存在しない場合、最新復元データ・世代・asset cleanupを変更する前に保存を拒否します。
- v0.1.11以前で作られた不完全な最新復元レコードも読込時に無効として扱い、正常な保存世代があれば自動的にフォールバックします。
- content-addressed recovery assetを再利用する前にサイズとSHA-256を確認します。
- キャッシュ画像が破損していても、次の正常なautosaveに同じ画像が含まれていれば、検証済み画像バイトから原子的に修復します。
- 不完全autosaveが直前の正常データを置き換えないこと、旧不完全currentからのfallback、破損assetの自己修復を回帰テストへ追加しました。

`.sbeproj`形式、Recoveryの形式バージョン、3つのワークスペース、Quick Retouch、背景削除、白黒変換、必須ランタイム依存関係は変更していません。

## English

- Reject autosave snapshots with missing logical image references before replacing current recovery data, creating generations, or cleaning assets.
- Treat legacy incomplete current recovery records as invalid and fall back to the newest valid generation.
- Verify content-addressed recovery assets by size and SHA-256 before reuse.
- Atomically repair a corrupt cached recovery asset from the next validated snapshot containing the same image.
- Add regressions for all three recovery failure paths without changing project or recovery schema versions.

## Windows x64 assets

- `SpeechBubble4komaEditor-v0.1.12-win-x64-setup.exe`
- `SHA256SUMS.txt`

The release workflow checks Windows FileVersion `0.1.12.0`, validates the complete repository on Windows/Ubuntu plus Chromium, silently installs the built package, verifies installed Quick Retouch assets, and refuses to overwrite an existing release. Interactive Windows/WebView2 visual testing remains separate from these automated gates.
