# Speech Bubble 4koma Editor v0.1.9

Maintenance and robustness release for the Windows standalone editor.

## Changes

- Harden Desktop/editor JSON and image APIs with bounded streaming reads.
- Reject malformed JSON roots, invalid Base64 and oversized encoded image data earlier.
- Bound `.sbeproj` image Base64 before decoding and ZIP image entries before reading them into memory.
- Stop the optional background-removal model download immediately if the response exceeds the expected model size.
- Check image pixel limits before full Pillow allocation.
- Restore overlap/radiant speech-bubble decorations in the Pillow compatibility renderer.
- Split SFX/frame Asset Catalogs from the Pillow renderer and lazy-load compatibility rendering.
- Align app/API/Windows version metadata at v0.1.9.
- Add Windows, Linux and Chromium regression validation.

## Compatibility

- Existing `.sbeproj`, recovery, layout, preset and user-asset formats are unchanged.
- Existing model URL/SHA-256 and web asset URLs are unchanged.
- No new mandatory runtime dependency was added.

## Assets

- `SpeechBubble4komaEditor-v0.1.9-win-x64-setup.exe`
- `SHA256SUMS.txt`

The installer is built from the tagged commit by GitHub Actions and the checksum file is generated from that build.
