# Speech Bubble 4koma Editor v0.1.10

Page Images and Black & White Conversion integration release for the Windows standalone editor.

## Changes

- Share one document-scoped Page Image Library between 4-Panel Manga and Comic workspaces.
- Make images added in either comic workspace immediately available in the other workspace.
- Migrate legacy per-workspace Page Image records while preserving existing image IDs.
- Save shared Page Images once in `.sbeproj` while keeping existing project schema compatibility.
- Route Black & White Conversion output from both comic workspaces into the shared Page Image Library.
- Distinguish Single Image, 4-Panel Manga and Comic in the Black & White Conversion dialog.
- Keep grayscale, Black & White Comic, Simple Monochrome and XDoG 100 conversion modes.
- Fix Reset so selecting the Grayscale preset restores the actual grayscale processing mode.
- Preserve exact Single Image source context so external-file conversion does not inherit an unrelated selected layer.
- Aggregate Page Image storage counts and unused-image cleanup across both comic workspaces.
- Add Chromium regression coverage for cross-workspace Page Image sharing and Black & White Conversion.

## Compatibility

- Existing `.sbeproj`, recovery, layout, preset and user-asset formats remain compatible.
- Legacy 4-panel and Comic Page Image stores are migrated into the shared document-scoped store.
- Existing model URL/SHA-256 and web asset URLs are unchanged.
- No new mandatory runtime dependency was added.

## Assets

- `SpeechBubble4komaEditor-v0.1.10-win-x64-setup.exe`
- `SHA256SUMS.txt`

The installer is built from the release commit by GitHub Actions. The workflow verifies FileVersion `0.1.10.0` and generates the SHA-256 checksum from the built installer before publishing the GitHub Release.
